MANUAL DE USUARIO — SISTEMA DE BOCKETS

1. Introducción

Este manual describe el uso del Sistema de Solicitud de Bockets de Flores el Tandil. El sistema permite a los empleados registrar sus solicitudes de bockets florales de forma autónoma desde un panel táctil de autoatención, y permite al administrador gestionar el ciclo completo de las solicitudes, configurar el sistema y generar reportes.

1.1 Roles del Sistema

El sistema tiene dos roles de usuario con interfaces y funciones diferenciadas.

Tabla 1

1.2 Acceso al Sistema

Para acceder al sistema, abra el navegador (Chrome o Firefox) e ingrese la dirección que le indique el área de sistemas. En el PC del kiosco de autoatención, el sistema se abre automáticamente al hacer doble clic sobre el acceso directo en el escritorio.

El panel del operador y del administrador requieren inicio de sesión con usuario y contraseña. El empleado que usa el panel táctil no necesita iniciar sesión: solo ingresa su número de cédula.

2. Panel de Autoatención (Empleado / Operador)

El panel táctil está diseñado para operarse con el dedo directamente sobre la pantalla. No requiere teclado ni ratón. Los pasos para solicitar un bocket son tres.

2.1 Paso 1 — Ingresar la Cédula

Use el teclado numérico de la pantalla para ingresar su número de cédula completo. Los dígitos aparecen en el campo de texto superior. Si se equivoca, use la tecla ← para borrar el último dígito, o Limpiar para borrar todo. Al terminar, presione Continuar.
Si el sistema tiene un escáner de código de barras conectado, puede pasar su cédula por el escáner en lugar de digitar manualmente. El sistema reconoce el código automáticamente.

2.2 Paso 2 — Verificar Datos

El sistema busca su cédula y muestra una tarjeta con su nombre completo, documento y sede. Verifique que los datos corresponden a los suyos antes de continuar.

Si el sistema muestra el mensaje "Persona no encontrada", es posible que su cédula no esté registrada. En ese caso, solicite al operador de turno que la registre mediante el botón Registrar nueva persona que aparece en pantalla.

2.3 Paso 3 — Completar y Enviar la Solicitud

Seleccione el motivo de la solicitud en el menú desplegable. Si elige la opción Otro, aparece un campo adicional para describir el motivo específico. Si lo desea, puede agregar observaciones en el campo de texto correspondiente. Cuando esté listo, presione Guardar Solicitud.
Si la solicitud se registró correctamente, aparece la pantalla de confirmación con un visto bueno verde y el mensaje «Solicitud registrada con éxito». Presione Registrar otra solicitud para reiniciar el panel.

2.4 Registrar una Persona Nueva (Operador)

Si al buscar la cédula el sistema responde "Persona no encontrada", el operador puede registrar al empleado directamente desde el panel táctil.

Paso 1. Presione el botón Registrar persona que aparece debajo del mensaje de error. Se abre un formulario modal.
Paso 2. Complete los campos requeridos: tipo de documento, número de documento, primer nombre, primer apellido y sede. Los campos segundo nombre y segundo apellido son opcionales.
Paso 3. Presione Guardar Persona. El sistema registra a la persona y automáticamente la busca en el panel táctil para continuar con la solicitud.

3. Panel del Administrador

El administrador accede al sistema con su usuario y contraseña. El panel completo incluye las siguientes secciones, accesibles desde el menú lateral.

Tabla 3

3.1 Dashboard

El dashboard muestra en tiempo real el total de solicitudes, las solicitudes del período actual y el estado de cupos de cada sede. Las gráficas se actualizan automáticamente cada 30 segundos sin necesidad de recargar la página.

3.2 Gestión de Solicitudes

En la sección Solicitudes se listan todas las solicitudes registradas. Se pueden aplicar filtros por fecha, sede, estado de solicitud y nombre o documento del beneficiario.

Cambiar el estado de una solicitud

Haga clic en el ícono de vista (ojo) sobre la solicitud para abrir el detalle. En la parte superior derecha del detalle seleccione el nuevo estado en el menú desplegable y confirme el cambio.

Generar reporte PDF

En la sección de solicitudes, use el botón Generar Reporte. Seleccione el período y la sede (o todas las sedes) y confirme. El sistema genera un PDF con el listado de solicitudes del período seleccionado, listo para enviar al área de elaboración.

3.3 Gestión de Personas

La sección Personas permite buscar, editar y gestionar el estado de los beneficiarios registrados en el sistema.

Editar una persona

Use el campo de búsqueda para localizar a la persona por nombre o documento. Haga clic en el ícono de edición, modifique los campos necesarios y guarde los cambios.

Habilitar o inhabilitar

Una persona inhabilitada no puede registrar solicitudes en el panel táctil. Use los botones Inhabilitar o Habilitar según el estado actual de la persona.

Importar maestro desde Excel

Para cargar o actualizar el padrón completo de beneficiarios desde un archivo Excel:

Paso 1. En Personas → Cargar maestro, haga clic en Seleccionar archivo y elija el archivo Excel (.xlsx, .xls) con el padrón. El sistema acepta el formato Tandil y el formato Creos automáticamente.
Paso 2. El sistema analiza el archivo y muestra una vista previa con el resumen de cambios: personas nuevas, a actualizar, a reactivar, sin cambios y con errores. Revise el resumen antes de confirmar.
Paso 3. Presione Confirmar importación para aplicar los cambios, o Cancelar para descartar el archivo sin modificar datos.

3.4 Configuración del Sistema

La sección Configuración agrupa en pestañas todas las opciones de ajuste del sistema.

Pestaña General

Permite configurar el nombre de la organización, el tipo de período (mensual o semanal), el cupo por defecto para nuevas sedes, el nombre de la empresa destinataria y el destinatario de las solicitudes que aparece en los PDF.

Pestaña Control de Cupos

Muestra el cupo máximo, el cupo utilizado y el disponible por sede para el período actual. Para modificar el cupo de una sede, escriba el nuevo valor en el campo correspondiente y presione Guardar.

El cupo máximo no puede ser inferior al número de solicitudes ya registradas para esa sede en el período activo. Si intenta reducir el cupo por debajo de las solicitudes existentes, el sistema rechazará el cambio.

Pestaña Gestión de Sedes

Permite crear, editar y eliminar sedes. Cada sede requiere nombre, código corto y estado. Las sedes inactivas no aparecen en el panel táctil ni en los cupos.

Pestaña Motivos de Ramo

Define los motivos disponibles para seleccionar al registrar una solicitud. Los motivos marcados como Requiere detalle activan un campo adicional en el panel táctil para que el empleado especifique el detalle.

Pestaña Estados de Solicitud

Permite gestionar los estados del ciclo de vida de una solicitud (por ejemplo: Pendiente, En preparación, Entregado, Cancelado). A cada estado se le asigna un color que aparece en el listado de solicitudes.

Pestaña Usuarios

Lista todos los usuarios del sistema con su rol, estado y fecha de último acceso. Desde aquí el administrador puede cambiar la contraseña de cualquier usuario sin necesidad de conocer la contraseña anterior.

Para cambiar la contraseña de un usuario: Haga clic en el botón Cambiar contraseña junto al usuario correspondiente. En el formulario que aparece, ingrese la nueva contraseña (mínimo 8 caracteres), confírmela y presione Guardar.

3.5 Cambiar su Propia Contraseña

Cualquier usuario (administrador u operador) puede cambiar su propia contraseña desde el menú de usuario en la esquina superior derecha de la pantalla.

Haga clic sobre su nombre o avatar en la esquina superior derecha. En el menú desplegable seleccione Cambiar contraseña. Ingrese su contraseña actual, la nueva contraseña y la confirmación. Presione Guardar.

5. Recomendaciones de Uso

  • Realice una copia de seguridad de la base de datos al menos una vez por semana. El administrador de sistemas puede automatizar este proceso desde el servidor.
  • Cambie las contraseñas del sistema cada tres meses o cuando un usuario deje de tener acceso.
  • Actualice el padrón de beneficiarios al inicio de cada período importando el maestro actualizado desde el área de talento humano.
  • Antes de generar el reporte de entrega al área de elaboración, cambie el estado de las solicitudes del período a En preparación para llevar un control claro del proceso.
  • Si el PC del kiosco queda sin uso prolongado, configure el protector de pantalla del sistema operativo pero no apague el equipo durante el horario de atención.
