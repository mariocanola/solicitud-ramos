Importante: El equipo servidor debe tener IP fija en la red local para que los equipos clientes siempre lo encuentren en la misma dirección. Esto se configura en el paso 8.

2 Instalar Laragon

Laragon es el entorno local que provee Apache, MySQL y PHP en un solo paquete. Es la base sobre la que corre el sistema.

  1. Descarga Laragon Full desde laragon.org/download (incluye PHP, MySQL y Apache).
  2. Ejecuta el instalador como Administrador (clic derecho → Ejecutar como administrador).
  3. Acepta la ruta de instalación por defecto: C:\laragon
  4. Al finalizar, Laragon aparece en la barra del sistema (ícono junto al reloj).
  5. Haz clic en Start All para iniciar Apache y MySQL.

Verificar que funciona

Abre el navegador y entra a http://localhost. Debe aparecer la página de bienvenida de Laragon.

Los indicadores de Apache y MySQL deben estar en verde en la ventana principal de Laragon.

3 Instalar Composer

Composer es el gestor de dependencias de PHP. El sistema lo necesita para instalar la librería de exportación Excel.

  1. Descarga el instalador desde getcomposer.org/Composer-Setup.exe
  2. Ejecuta Composer-Setup.exe.
  3. Cuando solicite la ruta de PHP, selecciona:
    C:\laragon\bin\php\php-[versión]\php.exe
    (Laragon coloca la versión activa dentro de C:\laragon\bin\php\)
  4. Completa la instalación con las opciones por defecto.

Verificar la instalación

Abre una terminal nueva (Win + R → escribe cmd → Enter) y ejecuta:

composer --version

Debe mostrar algo como Composer version 2.x.x.

Nota: Si el comando no se reconoce, cierra y vuelve a abrir la terminal. La instalación de Composer actualiza las variables de entorno de Windows y la terminal anterior no las ve.

4 Copiar el código del proyecto

El proyecto debe quedar ubicado en la carpeta C:\laragon\www\flores\.

Opción A — Desde un ZIP entregado

  1. Copia el archivo flores-instalador.zip al equipo servidor.
  2. Extrae el contenido en C:\laragon\www\flores\

Opción B — Desde el repositorio Git

  1. Abre la terminal de Laragon (ícono de Laragon → Terminal) o cualquier cmd.
  2. Navega a la carpeta www de Laragon: 
    cd C:\laragon\www
  3. Clona el repositorio: 
    git clone [URL_DEL_REPOSITORIO] flores

Estructura esperada

Después de copiar, la carpeta debe verse así:

C:\laragon\www\flores\
├── app\
│   ├── controllers\
│   ├── models\
│   ├── views\
│   └── services\
├── public\
│   ├── index.php
│   └── js\
├── installer\
│   ├── sql\
│   ├── instalar_cliente.bat
│   └── LEEME.txt
├── composer.json
└── .env.example

5 Instalar dependencias PHP

El proyecto utiliza la librería phpoffice/phpspreadsheet para generar reportes Excel. Composer la descarga e instala automáticamente.

  1. Abre cmd o la terminal de Laragon.
  2. Navega a la carpeta del proyecto: 
    cd C:\laragon\www\flores
  3. Ejecuta el comando de instalación: 
    composer install --no-dev --optimize-autoloader
  4. Espera a que finalice la descarga. Se crea la carpeta vendor\ con todas las librerías.
Si ves un error "PHP not found": Reinicia el cmd luego de instalar Laragon, o agrega la ruta de PHP de Laragon (C:\laragon\bin\php\php-[versión]) a las variables de entorno PATH de Windows.

6 Configurar la base de datos

6.1 Crear la base de datos

  1. Asegúrate de que Laragon esté corriendo (Apache y MySQL en verde).
  2. Abre cmd e ingresa a MySQL: 
    mysql -u root -p
    En Laragon, la contraseña de root por defecto es vacía: solo presiona Enter.
  3. Crea la base de datos: 
    CREATE DATABASE flores_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

6.2 Importar los scripts SQL

Desde cmd, dentro de la carpeta del proyecto, ejecuta los tres scripts en este orden:

cd C:\laragon\www\flores

mysql -u root flores_db < installer\sql\01_schema.sql
mysql -u root flores_db < installer\sql\02_seed.sql
mysql -u root flores_db < installer\sql\03_eventos.sql
Si MySQL tiene contraseña, agrega -p después de root en cada comando.
ScriptDescripción
01_schema.sqlCrea todas las tablas (configuración, sedes, personas, solicitudes, etc.)
02_seed.sqlInserta los datos iniciales (motivos, estados, configuración base)
03_eventos.sqlPrograma el reinicio automático semanal de cupos de solicitudes

6.3 Crear el usuario administrador

Conéctate a MySQL y ejecuta la siguiente instrucción, reemplazando los valores según corresponda:

USE flores_db;

INSERT INTO usuarios (nombre, email, password, rol)
VALUES (
    'Nombre Administrador',
    'admin@ejemplo.com',
    SHA2('contraseña_segura', 256),
    'admin'
);
Importante: Anota las credenciales que ingreses. Las necesitarás para el primer acceso al sistema.

7 Configurar el archivo .env

El archivo .env contiene la configuración de conexión a la base de datos. Se crea a partir del archivo de ejemplo incluido en el proyecto.

  1. Abre cmd y navega al proyecto: 
    cd C:\laragon\www\flores
  2. Copia el archivo de ejemplo: 
    copy .env.example .env
  3. Abre el archivo con el Bloc de notas: 
    notepad .env
  4. Ajusta los valores según tu configuración:
# Base de datos
DB_HOST=localhost
DB_NAME=flores_db
DB_USER=root
DB_PASS=
DB_CHARSET=utf8mb4

# Aplicación
APP_DEBUG=false
DB_PASS queda en blanco si usas la contraseña por defecto de Laragon. Si la cambiaste en algún momento, ingrésala aquí.

Guarda el archivo y cierra el Bloc de notas.

8 Configurar el servidor web

8.1 Virtual host de Laragon

Laragon detecta automáticamente las carpetas dentro de C:\laragon\www\ y crea un dominio local por cada una. El proyecto queda disponible en:

http://flores.test

Para acceso desde la red local también se puede usar la IP directamente (ver sección 8.2).

8.2 Conocer la IP del servidor

Averigua la IP local del equipo servidor:

ipconfig

Busca la línea Dirección IPv4 bajo el adaptador de red activo. Ejemplo: 10.10.90.104

El sistema queda accesible desde cualquier equipo de la red en:

http://10.10.90.104/flores/public

8.3 Configurar IP fija en Windows

Para evitar que la IP del servidor cambie al reiniciar:

  1. Abre Panel de control → Centro de redes y recursos compartidos → Cambiar configuración del adaptador.
  2. Clic derecho en tu adaptador de red → Propiedades.
  3. Selecciona Protocolo de Internet versión 4 (TCP/IPv4) → Propiedades.
  4. Marca Usar la siguiente dirección IP e ingresa:
    • Dirección IP: la IP que obtuviste con ipconfig
    • Máscara de subred: 255.255.255.0
    • Puerta de enlace: la IP del router (generalmente termina en .1)
  5. Haz clic en Aceptar para guardar.

8.4 Abrir el puerto en el Firewall de Windows

Ejecuta este comando en cmd como Administrador:

netsh advfirewall firewall add rule name="Flores Sistema" dir=in action=allow protocol=TCP localport=80
Si usas un puerto diferente al 80 (por ejemplo 8001), cambia localport=80 por localport=8001.

9 Verificar la instalación

Antes de distribuir el acceso a otros equipos, verifica que todo funciona correctamente en el servidor.

  1. Confirma que Laragon está corriendo: Apache y MySQL en verde.
  2. Abre el navegador en el mismo equipo servidor y entra a: 
    http://localhost/flores/public
    o bien: 
    http://flores.test
    Debe aparecer la pantalla de inicio del sistema.
  3. Ingresa con el usuario administrador creado en el paso 6.3.
  4. Desde otro equipo de la misma red, abre: 
    http://[IP_SERVIDOR]/flores/public
    y verifica que carga correctamente.
Si el sistema carga en el servidor pero no desde otros equipos, revisa la configuración del Firewall (paso 8.4) y verifica que todos los equipos estén en la misma red local.

10 Instalar clientes (otros equipos)

Los equipos clientes no necesitan instalar PHP, Laragon ni ningún componente técnico. Solo requieren un acceso directo configurado con la URL del servidor.

Usando el script instalador (recomendado)

  1. Copia el archivo installer\instalar_cliente.bat al equipo cliente (por USB, red compartida, etc.).
  2. Doble clic en instalar_cliente.bat.
  3. Ingresa los datos cuando se soliciten:
    • IP del servidor: la IP fija configurada (ej. 10.10.90.104)
    • Puerto: 80 (o el que esté en uso)
    • Tipo de cliente:
      • 1 — Kiosco: pantalla de solicitudes a pantalla completa (para el panel táctil de autoatención del empleado)
      • 2 — Admin: dashboard administrativo normal
      • 3 — Ambos
  4. Se crean accesos directos en el escritorio:
    • Flores Kiosco → abre /solicitudes/nueva en pantalla completa
    • Flores Admin → abre el dashboard administrativo
El modo Kiosco requiere Chrome o Edge instalado en el equipo cliente. Sin uno de estos navegadores, el sistema abrirá en ventana normal sin pantalla completa.

Creación manual del acceso directo (alternativa)

Si no puedes ejecutar el script, crea un acceso directo al navegador con el siguiente destino:

Para Kiosco:

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --new-window "http://[IP]/flores/public/solicitudes/nueva"

Para Administrador:

"C:\Program Files\Google\Chrome\Application\chrome.exe" --new-window "http://[IP]/flores/public/dashboard"

11 Arranque automático

Para que el sistema esté disponible desde el momento en que el servidor enciende, sin necesidad de abrir Laragon manualmente:

  1. Abre Laragon.
  2. Haz clic en el ícono de engranaje (Settings).
  3. Activa las siguientes opciones:
    • Auto start
    • Start Laragon when Windows starts
    • Run as service (opcional — permite que funcione incluso sin usuario conectado)
  4. Cierra la configuración y reinicia el equipo para confirmar que Laragon inicia solo.
Con Run as service activo, el servidor responde incluso si nadie ha iniciado sesión en Windows. Esto es recomendable si el equipo servidor no tiene monitor o usuario permanente.

12 Solución de problemas

ProblemaCausa probableSolución
"No se pudo conectar a MySQL" MySQL no está corriendo Abre Laragon → Start All. Verifica que MySQL esté en verde.
La página no carga en el servidor Apache no está corriendo Verifica que Apache esté en verde en Laragon.
La página no carga desde otro equipo Firewall bloqueando el puerto Ejecuta el comando netsh del paso 8.4 como Administrador.
La página no carga desde otro equipo IP incorrecta en el cliente Re-ejecuta instalar_cliente.bat con la IP correcta del servidor.
Errores de clase o librería no encontrada La carpeta vendor\ no existe Ejecuta composer install desde la carpeta del proyecto.
Error ".env no encontrado" El archivo no fue creado Ejecuta copy .env.example .env y edita las credenciales.
"Flores Kiosco" abre en ventana normal Chrome o Edge no instalado Instala Chrome o Edge en el equipo cliente.
La IP del servidor cambió IP dinámica (DHCP) Configura IP fija en Windows (paso 8.3) y reinstala los clientes con la nueva IP.
Error al importar SQL Orden incorrecto o BD inexistente Verifica que flores_db exista antes de importar. Importa en orden: 01 → 02 → 03.
Contraseña admin incorrecta Hash incorrecto en el INSERT Ejecuta de nuevo el INSERT del paso 6.3 con la contraseña correcta.

Resumen rápido para instaladores con experiencia

  1. Instalar Laragon + presionar Start All
  2. Instalar Composer
  3. Copiar proyecto a C:\laragon\www\flores\
  4. Ejecutar composer install --no-dev --optimize-autoloader
  5. Crear BD flores_db e importar 01_schema.sql → 02_seed.sql → 03_eventos.sql
  6. Copiar .env.example a .env y ajustar credenciales
  7. Crear usuario administrador con INSERT en MySQL
  8. Configurar IP fija y abrir puerto en el Firewall
  9. Verificar en http://localhost/flores/public
  10. En cada cliente: ejecutar instalar_cliente.bat
