MANUAL DE INSTALACIÓN — SISTEMA DE BOCKETS

1. Introducción

Este manual describe el procedimiento para instalar y poner en marcha el Sistema de Solicitud de Bockets de Flores el Tandil en un equipo con sistema operativo Windows. El sistema opera en red local y no requiere conexión a internet para su funcionamiento.

El proceso de instalación comprende cuatro etapas: preparación del entorno (Laragon), configuración de la base de datos, configuración del archivo de entorno y verificación del inicio del sistema.

1.1 Requisitos del Sistema

Antes de iniciar la instalación, verifique que el equipo servidor cumple con los siguientes requisitos.

1.2 Software Necesario

El sistema requiere los siguientes componentes de software, todos incluidos en la distribución de Laragon.

  • Laragon (versión Full o Lite con PHP y MySQL): gestor de entorno de desarrollo local para Windows
  • PHP 8.0 o superior: lenguaje de servidor del sistema
  • MySQL 5.7 o superior (o MariaDB equivalente): motor de base de datos
  • Apache HTTP Server: servidor web incluido en Laragon
  • Composer (opcional): si se requiere reinstalar dependencias PHP
Advertencia: No instale versiones de PHP inferiores a 8.0. El sistema usa funciones y extensiones que no están disponibles en versiones anteriores.

2. Instalación de Laragon

Laragon es el entorno que provee Apache, PHP y MySQL en un paquete único para Windows. Si Laragon ya está instalado y funcionando en el equipo, avance directamente a la sección 3.

2.1 Descarga e Instalación

Paso 1. Descargue el instalador de Laragon Full desde el sitio oficial: https://laragon.org/download/. Seleccione la versión «Full» que incluye PHP, MySQL y Apache.
Paso 2. Ejecute el instalador como administrador. Acepte la ruta de instalación predeterminada (C:\laragon). Cambie la ruta solo si tiene una razón específica; en ese caso, ajuste las rutas en los scripts de inicio del sistema.
Paso 3. Al finalizar la instalación, abra Laragon desde el escritorio o el menú de inicio. Haga clic en Start All para iniciar Apache y MySQL. Verifique que ambos indicadores muestren verde.
Paso 4. Abra un navegador y acceda a http://localhost. Si aparece la pantalla de bienvenida de Laragon, la instalación fue exitosa.

3. Instalación del Sistema

3.1 Copiar los Archivos

El sistema debe ubicarse en la carpeta www de Laragon para que Apache lo sirva correctamente.

Paso 1. Abra el Explorador de Windows y navegue hasta C:\laragon\www\.
Paso 2. Copie la carpeta completa del sistema (flores) dentro de C:\laragon\www\. La estructura resultante debe verse así: 
C:\laragon\www\flores\
    ├── app\
    ├── docs\
    ├── public\
    ├── storage\
    ├── vendor\
    ├── iniciar.bat
    ├── iniciar_kiosco.bat
    └── .env.example
Paso 3. Verifique que la carpeta vendor\ existe y contiene archivos. Si está vacía o no existe, abra una terminal en la carpeta del sistema y ejecute: 
composer install --no-dev

3.2 Crear la Base de Datos

Paso 1. Abra phpMyAdmin desde Laragon (menú Database → phpMyAdmin) o acceda desde el navegador a http://localhost/phpmyadmin.
Paso 2. Cree una nueva base de datos con el nombre flores_db y cotejamiento utf8mb4_unicode_ci.
Paso 3. Seleccione la base de datos recién creada. En la pestaña SQL, importe el script de estructura ubicado en: 
C:\laragon\www\flores\database\flores_db.sql
Haga clic en Importar, seleccione el archivo y confirme. El script crea todas las tablas y los datos iniciales (incluyendo el usuario administrador por defecto).
Credenciales por defecto del administrador:
Usuario: admin
Contraseña: admin1234
Cambie la contraseña inmediatamente después del primer acceso desde el menú de usuario en la esquina superior derecha.

3.3 Configurar el Archivo de Entorno

El sistema lee su configuración de conexión desde un archivo .env ubicado en la raíz del proyecto.

Paso 1. Navegue hasta C:\laragon\www\flores\ y copie el archivo .env.example con el nombre .env: 
Copiar .env.example  →  .env
Paso 2. Abra el archivo .env con un editor de texto (Notepad, VS Code, etc.) y ajuste los siguientes valores: 
DB_HOST=localhost
DB_NAME=flores_db
DB_USER=root
DB_PASS=
APP_DEBUG=false
Si MySQL tiene contraseña configurada en su instalación, colóquela en DB_PASS. En instalaciones estándar de Laragon, la contraseña del usuario root está vacía.
Paso 3. Guarde el archivo. Nunca comparta ni publique el archivo .env ya que contiene credenciales de acceso.

3.4 Verificar Permisos de Escritura

El sistema escribe archivos PDF y logs en la carpeta storage\. Esta carpeta debe tener permisos de escritura para el proceso de Apache.

Paso 1. En el Explorador de Windows, haga clic derecho sobre C:\laragon\www\flores\storage\.
Paso 2. Seleccione Propiedades → Seguridad → Editar y asegúrese de que el usuario bajo el cual corre Apache (generalmente SYSTEM o el usuario actual) tenga permiso de escritura. En la mayoría de instalaciones de Laragon en modo desarrollo esto es automático.

4. Inicio del Sistema

4.1 Usando los Scripts de Inicio

El sistema incluye dos scripts de inicio en la raíz del proyecto que automatizan la verificación de servicios y la apertura del navegador.

Tabla 2
Scripts de inicio disponibles
ArchivoUsoDescripción
iniciar.batUso general / administrativoVerifica Apache y MySQL, inicia Laragon si es necesario y abre el navegador en el panel principal del sistema
iniciar_kiosco.batPC de autoatención (kiosco)Igual que el anterior, pero abre el navegador en modo pantalla completa (kiosco) directamente en el panel del operador para que el empleado pueda ingresar su cédula
Para iniciar: Haga doble clic sobre el archivo iniciar.bat o iniciar_kiosco.bat según corresponda. El script verifica los servicios y abre el navegador automáticamente. Si Laragon no está iniciado, el script lo inicia y espera a que los servicios levanten.
Nota: Si la ruta de Laragon en su equipo es diferente a C:\laragon\, abra el archivo .bat con un editor de texto y ajuste la variable LARAGON al principio del archivo.

4.2 Inicio Manual

Si prefiere iniciar los servicios manualmente sin usar los scripts:

  1. Abra Laragon desde el escritorio y haga clic en Start All.
  2. Espere a que Apache y MySQL muestren estado verde.
  3. Abra el navegador y acceda a: http://localhost:8001 (o la URL configurada en su instalación de Laragon).
  4. Ingrese con las credenciales de administrador.

5. Configuración Inicial Post-Instalación

Tras la primera instalación, realice las siguientes configuraciones antes de poner el sistema en operación.

1. Cambiar la contraseña del administrador. Inicie sesión con las credenciales por defecto, haga clic en el nombre de usuario (esquina superior derecha) y seleccione Cambiar contraseña. Elija una contraseña segura de al menos 8 caracteres.
2. Configurar la organización. En el menú Configuración → General, ingrese el nombre oficial de la organización y los datos del destinatario para los PDF.
3. Crear sedes. En Configuración → Gestión de Sedes, registre las sedes activas. Cada sede debe tener nombre, código corto (ej. TN, PM) y estado Activa.
4. Configurar cupos. En Configuración → Control de Cupos, establezca el número máximo de solicitudes por sede para el período actual.
5. Importar beneficiarios. En el menú Personas → Cargar maestro, importe el archivo Excel con el listado de personas activas. El sistema acepta el formato Tandil y el formato Creos, detectando automáticamente la estructura del archivo.
6. Crear usuario operador (si aplica). El operador del kiosco necesita una cuenta con rol Operador. Desde Configuración → Usuarios puede gestionar las cuentas y contraseñas. Para crear un nuevo usuario, actualmente se hace directamente en la base de datos o mediante el script SQL de creación de usuarios incluido en database/.

6. Verificación Final

Antes de entregar el sistema en producción, verifique que los siguientes puntos funcionan correctamente.

  • El administrador puede iniciar sesión y acceder al dashboard.
  • El operador puede iniciar sesión y ver el panel de autoatención.
  • Al ingresar la cédula de un beneficiario en el panel táctil, el sistema lo identifica y permite registrar una solicitud.
  • La generación del reporte PDF produce un archivo descargable sin errores.
  • La importación de un archivo Excel de prueba se procesa correctamente.
El sistema está listo para operar cuando todos los puntos anteriores responden sin error. Para soporte técnico, contacte al desarrollador: Mario Alexander Cañola Cano.
